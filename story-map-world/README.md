# story-map-world — мир игры для Story Map

| Файл | Для чего |
|---|---|
| `00-WORLD-MAP.md` | Обзор всего мира: масштаб, кто действует, переменные, что может произойти, открытые вопросы |
| `md/*.md` | То же по категориям — читать и писать правки |
| `json/*.json` | То же по категориям в формате «📥 Импорт идеи» Story Map |
| `story.json` | Весь мир одним файлом — онлайн-Story Map загружает его сам |
| `src/world-data.js` | **Единственный источник.** Всё остальное (кроме `00-WORLD-MAP.md`) собирается из него |
| `src/build.js` | Сборка: `node story-map-world/src/build.js` — заодно проверяет, что все ссылки на узлы, переменные и сущности существуют |

Пометки: ✅ есть в дизайн-документе · 💡 предложение · ❓ не решено.

Онлайн: Story Map открывает `story.json` автоматически. Другой файл — `story-map/?data=<путь>`.
Правки, сделанные в браузере, в репозиторий не попадают — «⬇ Скачать JSON» и прислать файл.
