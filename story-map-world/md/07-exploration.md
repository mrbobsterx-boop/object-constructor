# Исследование, лут и переходы

Мир физический: игрок сам идёт, переходы через двери, края, лестницы, указатели (§4). Места меняют состояние (§18).

Пометки: ⭐ решение автора · ✅ из GDD · 💡 предложение · ❓ не решено. Источник правок — `src/world-data.js`, этот файл собирается автоматически.

## 💡 Первый выход наружу

`exploration.first_exit` · Игрок · после другого события

Окрестности бункера: тишина, следы на земле, указатель вдали.

Участвуют: Окрестности бункера

**Меняет:** Шумность игрока +5

**Дальше:**
- К дороге → *Указатель на развилке*
- Идти по следам → *Следы чужого присутствия*
- Обыскать ближний дом → *Дом: в каком он состоянии*

## ✅ Указатель на развилке

`exploration.signpost` · Локация · после другого события · GDD §4.2

Участвуют: Главная трасса и развилки

**Дальше:**

## ✅ Дом: в каком он состоянии

`exploration.house_states` · Локация · после другого события · GDD §18

Обычный, ограбленный, покинутый в спешке, частично разрушенный, недавно покинутый, занятый выжившими.

Участвуют: Городок

**Дальше:**
- Недавно покинут → *Еда ещё тёплая*
- Заперт → *Запертая дверь*
- Уже ограблен → *Кто-то успел первым*
- Тайник → *Тайник с консервами*
- Тело внутри → *Тело незнакомца*
