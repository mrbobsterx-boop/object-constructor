Инструмент

Тяни мышкой рамку вокруг объекта и нажми Space — рамка обрежется по непрозрачному содержимому (как кнопка «Обрезать пустое пространство») и станет новым слоем. Пиксели внутри не трогаются — если у листа непрозрачный фон, сотри его ластиком уже на слое. Esc — отменить рамку.

Потяни за квадратик на краю или углу. Боковой — тянет одну сторону, угол — обе (с Shift — пропорционально).

Название слоя (по плану объектов)

Выбор раздела и объекта сохраняется между слоями — меняй только вариацию для следующего объекта того же типа.
+ своя категория / объект / вариация
Попадёт в свои объекты Object Plan — если раздел+объект уже существуют, вариация просто добавится к нему.

Проверка перед сохранением

Всё, что не до конца стёрлось, станет ярко-красным.

Действия (для активного холста — лист или слой)

Ctrl+Z — отменить, Ctrl+Shift+Z — вернуть, Delete — удалить активный слой.

Сохранение

Слои сохраняются по своим именам (из плана или своим текстом) в assets/refs/. Существующие файлы не перезаписываются — добавляется номер.
