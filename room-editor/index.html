🧱 Блоки: разрушаемый грунт и стены
Блоки ставятся целыми (рамкой по сетке 1 м) и стыкуются встык, без зазоров. Куски 20×20 см ломаются уже в игре. Тип блока — объект категории «Блок / материал» из ОС («все объекты» показывает остальные). Твёрдые куски считаются красной зоной: на них встают объекты, внутрь ставить нельзя. Внешние углы массива срезаются фаской; у границы комнаты срез не рисуется.
Кликни по объекту в комнате, чтобы увидеть его свойства. Перетащи объект из библиотеки слева на холст, чтобы разместить.
