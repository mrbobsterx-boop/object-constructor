# Story Map — справочник

Визуальный конструктор сюжетных узлов и переходов: события, выборы игрока, фоновые (не зависящие от игрока) события, и то, как всё это меняет мир — репутацию фракций, уровень опасности, счётчики дней и любые другие авторские переменные. Не редактор игровых данных ОС/Room Editor/Building Editor — отдельный слой, описывающий сюжет и последствия, на основе которого потом пишется код игры и ИИ. Пишет только `data/story.json`. Читает его `story-bot/` (симулятор прохождения, `10-Story-Bot.md`).

Запуск: открыть `story-map/index.html` в Chrome/Edge.

---

## 1. Мировые переменные

Авторский список (левая панель, «Мировые переменные»): `id` (генерируется), название, тип (**число** — счётчик типа репутации или уровня опасности; **флаг** — просто да/нет) и начальное значение. Условия и эффекты узлов/переходов ссылаются только на переменные из этого списка — «Проверки» (см. ниже) ловят ссылки на удалённую или ещё не созданную переменную.

## 2. Узлы

Три вида (влияют только на цвет рамки и подсказки по умолчанию — структура одна и та же):
- **Событие** — обычный сюжетный момент.
- **Выбор** — момент с явным решением игрока (несколько переходов).
- **Фоновое** — то самое «мир живёт сам»: срабатывает по внутриигровому таймеру, независимо от игрока.

У каждого узла: название, текст (что видит игрок), **когда доступен** (`Когда доступен`):
- **▶ Старт** — доступен сразу, с него начинается игра (должен быть ровно один такой узел — иначе «Проверки» пожалуются).
- **⚑ По условиям** — список условий (переменная / знак `≥ ≤ = ≠ > <` / число), все должны выполняться.
- **⏱ Фоновое, по таймеру** — срабатывает само через N игровых часов после старта игры или после того, как сработал другой указанный узел; можно включить «повторять».

**Что меняет при срабатывании** — список эффектов (переменная / `= + −` / число), применяется, когда узел срабатывает (для фоновых — сам по таймеру, для остальных — когда игрок до них доходит).

**Параметры для бота-симулятора** — не игровые данные ОС, а числа для `story-bot`: длительность в игровых часах, шанс опасности (0…1), расход еды/воды (**отрицательное число — восполняет**, например «поесть»), какие предметы/навыки нужны (свободный текст через запятую, справочно — движок бота их не проверяет автоматически).

**Концовка** — если заполнено (например `death`, `victory`, своя строка), узел считается финалом: бот останавливает прогон и засчитывает эту концовку в статистику.

## 3. Переходы (связи)

Два способа создать: **потянуть за кружок** на правом краю узла на холсте до другого узла (перетаскивание пустого места холста — панорама; колёсико — масштаб), или кнопкой «+ добавить переход» в инспекторе. У каждого перехода — текст, целевой узел, свои «Требуется» (условия, как у узла) и «Меняет» (эффекты, в дополнение к эффектам самого узла).

## 4. Проверки

Тот же принцип, что в Project Registry/Object Plan (уровень err/warn/info):

| Проблема | Смысл |
|---|---|
| Нет стартового узла | Ни один узел не отмечен «▶ Старт» |
| Ссылается на несуществующую переменную | Условие/эффект использует id переменной, которой нет в списке (или её удалили) |
| Переход ведёт в несуществующий узел | `target` перехода не совпадает ни с одним id узла |
| Отсчёт таймера от несуществующего узла | `sinceNode` фонового узла не существует |
| Тупик без развития (info) | У узла нет ни переходов, ни отметки концовки |
| Недостижим (info) | Ни один переход и ни одно стартовое/фоновое событие не ведёт на этот узел |

## 5. Хранение и формат

Пишет только `data/story.json`: `{schema_version, variables:[{id,name,type,start,min,max}], nodes:[{id,title,text,type,x,y,trigger,effects,sim,choices,ending}]}`. `Ctrl+Z`/`Ctrl+Shift+Z` — отмена/возврат (история правок графа в браузере, не файла на диске).

## 6. Скрипты (модули)

| Файл | За что отвечает |
|---|---|
| `01-core-utils.js` | Папка проекта (File System Access API, IndexedDB `story_map_fs`), `esc`/`sanitizeSlug`/`uid`, `OP_LIST`/`opTest` |
| `02-graph-state.js` | `variables`, `nodes`, выбор узла, CRUD (`addNode`/`updateNode`/`addChoice`…), история отмены/возврата |
| `03-canvas.js` | Левая панель (списки), холст: перетаскивание узлов, панорама/масштаб, соединение кружком, отрисовка SVG-связей |
| `04-inspector.js` | Правая панель — редактор выбранного узла по «путям» (`data-path`, точечная нотация) |
| `05-checks.js` | Проверки графа |
| `06-save-load.js` | Чтение/запись `data/story.json` |
| `07-init.js` | Кнопки, масштаб, горячие клавиши, восстановление папки (**всегда последним**) |
