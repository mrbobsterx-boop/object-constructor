# Image Prep Tool — справочник

Приложение для подготовки картинок объектов из фотографий/скана листа под ОС: вырезать объект в отдельный слой, стереть лишнее ластиком, обрезать пустое пространство, назвать слой по каталогу Object Plan и сохранить как PNG в `assets/refs/`. Игровых данных не пишет — это вспомогательный инструмент художника, результат (обрезанные PNG) руками переносится/используется как референс при рисовании в ОС или сохраняется в `assets/refs/` для превью в Object Plan.

Запуск: открыть `ipt/image-prep-tool/index.html` в Chrome/Edge.

---

## 1. Инструменты

| Инструмент | Клавиша | Что делает |
|---|---|---|
| 🪄 Клик по объекту — рамка сама | `C` | Заливка по альфа-каналу (не по цвету) от точки клика ищет связную непрозрачную область и сама строит рамку вокруг неё (с отступом), затем вырезает как обычное выделение. Клик в прозрачную область — ничего не делает; если на листе нет прозрачного фона вовсе (рамка касается всех краёв) — отказывает и просит выделить вручную |
| ▭ Выделение | `M` | Тянешь рамку мышкой, `Space` — вырезает прямоугольник в новый слой (обрезая по непрозрачному контенту, как «Обрезать пустое пространство»); пиксели внутри не трогает |
| 🧽 Ластик | `E` | Стирает (прозрачность), с мягкостью и размером кисти |
| 🖌 Восстановить | `R` | Возвращает стёртое из исходной картинки слоя |
| ↔ Растянуть за края | `T` | Растягивает холст слоя за угловые/боковые ручки |

Общие: `Ctrl+Z`/`Ctrl+Shift+Z` — отмена/возврат, `Delete`/`Backspace`/`X` — удалить активный слой, `Q`/`Й` — обрезать пустое пространство, `Tab` — следующий слой, `1`–`9` — слой по номеру, `[`/`]` — размер кисти.

## 2. Именование слоёв

Панель «Название слоя» подключает словарь Object Plan (`object-plan/js/02-05-*.js`) напрямую — раздел/объект/вариация всегда совпадают с тем, что видит сам Object Plan. Выбор раздела и объекта «липкий» (сохраняется между захватами слоёв), вариацию меняешь под каждый новый объект. «+ вариация» добавляет вариацию к уже выбранному объекту без пересоздания; «+ своя категория/объект/вариация» заводит объект, которого в каталоге ещё нет.

## 3. Сохранение

«💾 Сохранить всё» пишет каждый слой отдельным PNG в `assets/refs/` под именем `<id>_<вариация-en>.png` (существующие файлы не перезаписываются — добавляется номер). Это ровно тот путь и формат имени, который Object Plan (`refThumbFor`/`refStateThumbs`, `07-store.js`) ищет для превью вариации.

**Состояния превью (idle/broken/icon).** Сам Image Prep Tool суффикс состояния не проставляет — он появляется, когда те же файлы после потом обрабатывает **Asset Renamer** (`08-Asset-Renamer.md`), который добавляет к имени `_idle`/`_broken`/`_icon`. Если такого суффикса нет (файл сохранён прямо отсюда), Object Plan считает его `idle`.

## 4. Скрипты (модули)

| Файл | За что отвечает |
|---|---|
| `01-core-utils.js` | Папка проекта (File System Access API, IndexedDB `img_prep_fs`), транслитерация/слаги (совпадают с Object Plan) |
| `02-plan-bridge.js` | Мост к словарю Object Plan: `planEffectiveGroups()`, `planAllItems()`, `planItemById()`, свои объекты/вариации, чтение/запись `data/object_plan.json` |
| `03-queue.js` | Очередь открытых картинок |
| `04-canvas-core.js` | Холст, зум, линейки, история (undo/redo) |
| `05-layers.js` | Слои: захват из листа, список, удаление |
| `06-tools-paint.js` | Переключение инструментов, ластик/восстановить, растянуть за края |
| `07-tool-select.js` | Выделение рамкой, авто-выделение по альфа-заливке (`findOpaqueRegionAt`, `handleAutoSelectClick`), обрезка пустого пространства |
| `08-naming-panel.js` | Панель именования по каталогу Object Plan |
| `09-save.js` | Сохранение слоёв в `assets/refs/` |
| `10-init.js` | Файлы/вставка/drag&drop, горячие клавиши (**всегда последним**) |
