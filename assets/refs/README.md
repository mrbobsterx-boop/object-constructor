Правильно названные превью объектов — то, что видит Object Plan (`refThumbFor()`/`refStateThumbs()` в `object-plan/js/07-store.js`) и каталог Story Map. Имя файла: `<id>_<вариация>_<состояние>.png`, где `<состояние>` — `idle`/`broken`/`icon` (см. `MD/08-Asset-Renamer.md`).

Файлы сюда переносятся (копируются) из `assets/sprites/` — туда продолжайте загружать новые сырые картинки, они будут обработаны следующим проходом.
